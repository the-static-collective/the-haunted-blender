## Absolute scoring

The Doctor samples the rendered MP4 itself at low resolution and combines that with 008e source provenance.

Each 1–10 second window receives bounded scores for:

- stasis
- source overuse
- recent source repetition
- novelty deficit
- transition jolt

Scores use absolute thresholds so before/after rescans are comparable.

```text
WEAKNESS SCORE != AESTHETIC TRUTH
OBSERVED MOTION != MEANING
```

## Default weights

```text
stasis            30%
source overuse     25%
recent repetition  20%
novelty deficit    15%
transition jolt    10%
```

The weights are triage, not taste.

## Mutation ladder

```text
LEVEL 0  keep
LEVEL 1  deterministic remix
LEVEL 2  owned-clip compost
LEVEL 3  topology / text / cutout treatment
LEVEL 4  repeatably-free provider
LEVEL 5  regenerating included allowance
LEVEL 6  finite credit
LEVEL 7  paid hero shot
```

Automatic treatment stops at Level 1.

If Level 1 fails, the next recommendation is owned-clip compost — not paid generation.

## Closed loop

One command performs the whole trial loop:

```bash
python -m haunted_blender.weakest_window_cli smash \
  ./film/zero-dollar/zero-dollar-current-cut.mp4 \
  ./film/zero-dollar/zero-dollar.plan.json \
  /path/to/source-videos \
  ./film/doctor-pass-001 \

```

It writes:

```text
doctor.before.json
doctor.treatment.json
doctor.level1.plan.json
level1-trial/
doctor.after.json
doctor.verdict.json
```

## Verdict law

The original cut remains untouched.

The Level-1 render is a trial until the rescore supports improvement.

```text
TRIAL OUTPUT != CURRENT CUT UNTIL VERDICT
PRESCRIPTION != IMPROVEMENT
RESCORE AFTER TREATMENT
COVERAGE MAY NOT DECREASE
```

If mean weakness drops and coverage is preserved, the Level-1 trial is accepted as an improvement candidate.

If not:

```text
FAILED LEVEL 1
  ≠ spend credits

FAILED LEVEL 1
  → LEVEL 2 owned-clip compost
```

## Why this changes the economics

Once 100% coverage exists, the machine no longer asks for more footage by default.

It asks:

```text
Which existing seconds are weakest?
Which zero-dollar transformation improves them?
How much film does that improvement affect?
```

Only after local deterministic and owned-material treatments are exhausted does a repeatably-free provider enter the ladder.
