# FRANKEN BLENDER 008j — PAPER DIRECTOR / SHOT GRAMMAR\n\n008e guarantees enough movie.\n\n008f identifies weak windows.\n\n008g builds the reusable paper world.\n\n008h turns owned videos into parts.\n\n008i lets moving harvested parts live inside that world.\n\n008j directs the completed world.\n\n```text\nONE COMPLETED PERFORMANCE\n        ↓\nSHOT GRAMMAR\n        ↓\nMANY POSSIBLE CUTS\n```\n\n## Direct the view, not the performance\n\n008j does not rewrite puppet joints, lyric timing, harvested-source authority, moving-insert authority, or soundtrack authority.\n\nIt takes an already-rendered movie and decides how the existing frame is viewed over time.\n\n```text\nDIRECTING MAY CHANGE VIEW\nWITHOUT CHANGING WORLD\n```\n\nThe undirected puppet movie remains a separate witness.\n\n## Shot vocabulary\n\nThe initial grammar includes:\n\n```text\nESTABLISH\nWIDE\nSPEAKER\nCLOSE_UP\nREACTION\nINSERT\nLYRIC_WORLD\nCHAOS\nRETURN\n```\n\nThese are deterministic crop / scale / flip operations over existing rendered pixels.\n\n## Music / lyric grammar\n\nNormalized Full Measure / PlayDeck timing remains the structural input.\n\nExamples:\n\n```text\nquestion mark\n  → reaction\n\nexclamation\n  → close-up\n\nchorus\n  → wide / close / lyric-world rotation\n\nbridge\n  → lyric-world / reaction / close\n\ngap between cues\n  → reaction / reset\n\nsong tail\n  → return\n```\n\nSection and punctuation signals are heuristics, not aesthetic truth.\n\n## Weak-window directing\n\nWhen an 008f Doctor report is available, high-weakness windows influence framing before any new media is requested.\n\nIf a weak stasis/repetition window already contains an 008i moving surface:\n\n```text\nWEAK WINDOW\n   +\nEXISTING TELEVISION / WINDOW / PORTAL\n   ↓\nINSERT CLOSE-UP\n```\n\nThe Director reaches into an admitted surface already present in the world.\n\n```text\nINSERT SHOT MUST BIND EXISTING MOVING SURFACE\n```\n\n## Anti-boredom law\n\n008j enforces a configurable maximum shot duration.\n\nAny shot that exceeds that threshold is split and re-framed.\n\nAdjacent shots are not allowed to repeat the same framing when a bounded alternative exists.\n\n```text\nIF SHOT TOO LONG\n  → REFRAME\n\nIF SAME SHOT REPEATS\n  → ALTERNATE VIEW\n```\n\nThe default maximum is 3.2 seconds.\n\n## Cheap reactions\n\nA reaction shot is usually the same underlying performance viewed through a tighter or offset crop.\n\n```text\nspeaker\n  ↓\nHARD CUT\n  ↓\nsame performance / reaction framing\n  ↓\nCUT BACK\n```\n\nNo new animation is required.\n\n## Existing inserts become story events\n\n008i televisions, windows, portals, and advertisements can now become actual directed shots.\n\nThe Director uses the frozen insert box as the crop target and includes its bezel padding.\n\n```text\nCHARACTER WORLD\n   ↓\nCUT TO TV\n   ↓\nHARVESTED FLOW / AI FOOTAGE\n   ↓\nCUT BACK\n```\n\nThat turns owned footage into events inside the paper movie rather than unrelated montage.\n\n## Lyric-world framing\n\n`LYRIC_WORLD` crops toward the lower physical lyric geography produced by 008g.\n\nThe words remain scenery rather than becoming a new subtitle system.\n\n## Rendering\n\nEach shot is accurately trimmed from the completed base movie, reframed, scaled back to the original canvas, and encoded as a temporary video-only segment.\n\nThe segments are concatenated into a new directed video.\n\nIf the base movie has audio, 008j remuxes/re-encodes only that base audio onto the final directed picture.\n\n```text\nBASE PERFORMANCE RETAINS AUDIO AUTHORITY\n```\n\n## One-command director\n\nStandalone:\n\n```bash\npython -m haunted_blender.paper_director_cli smash
