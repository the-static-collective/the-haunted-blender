# Private media, provenance and production rights

Photographs and voice recordings may be intimate. Local-only processing is the default. Importing a file gives no permission to identify its subjects, infer private biographical facts, train models, share images, clone voices, or publish the result. A proposed film scene is not evidence of a real event.

- Keep a source image, RAW original, Lightroom sidecar, export, AI alteration and filmed take distinct.
- Allow explicit user-attested identity and rights notes without silently promoting pattern matches into facts or consent.
- Declare documentary claims, reconstruction, fictional scenes, user reports and uncertainty distinctly.
- External generation must disclose exactly what media leaves the machine, destination/service, costs and use rights before opt-in.
- The v0 catalog is unencrypted local SQLite with absolute paths; it is **not** a security-hardened encrypted vault.
- Never commit personal archive data, EXIF location metadata, source images, library files, receipts or personal project manifests to the public repository.
- Before production deployment add backup/restore, permissions, installer security, interruption tests and release safeguards.
