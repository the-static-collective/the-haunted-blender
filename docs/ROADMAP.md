# NUKLEAR COUNTDOWN — dependency gates, not delivery dates

Wide ambition; bounded executable landings. Internal component tests are mandatory during development. Invite outside filmmakers only when the complete-film milestone is coherently usable.

## N0 — repository and executable foundation
Separate product charter, rights boundary, film/scene/shot manifests, local path/digest catalog, explicit CR2-to-edited-derivative relationship, frozen snapshots, elementary silent-FFmpeg storyboard renderer, scoped output receipt. This is **not** a completed film generator.

## N1 — The 10,000-photo Pantry
Resumable 10k/100k archive benchmark with crash/restart, duplicate/moved files, disk pressure, corrupt inputs and originals-unchanged proofs. EXIF and XMP ingestion without claiming Adobe rendering parity. Bounded thumbnail/cache engine, opt-in local search and relationship proposals, rights/identity confirmation, visual archive browser. **Exit:** realistic target-device benchmark and recovery report.

## N2 — three-scene drama
Script/scene/beat director, manually approved source associations, optional narration/dialogue/captions, local renderer adapter, first verified AgentBroko integration, editable shot sequence and exportable project. **Exit:** idea or archive → editable three-scene movie with picture+sound → MP4 → revise scene two only → re-export → reopen project. Prove untouched shots and input/cost boundaries.

## N3 — episodes and editing
Cross-episode cast/location library, continuity questions, multi-track non-linear picture and sound editing, independent takes, scoped collaboration and performer permissions. **Exit:** two related episodes with consistent scene identifiers and repeatable revisions.

## N4 — authored virtual production
Verified Blender 3D and optional bounded local/cloud generation adapters; scene grammar, parallax, camera/light rigs, set reuse, motion/performance and explicit usage costs. **Exit:** one scene migrates from photo storyboard to 2.5D and 3D without changing its narrative identity.

## N5 — AAA release hardening
Accessible Spark/Director/Expert surfaces sharing the same schema, portable backup/restore, reversible migration, installer, capability and hardware discovery, crash recovery, credible rights/licensing, color/audio/export QC, security and performance testing. **Exit:** independent filmmakers can complete a project without a developer steering each step.

## First filmmaker-facing test gate
1. A real CR2 + edited Lightroom export imports without altering either; 10k-scale ingest recovers from interruption.
2. A filmmaker can select a story, curate images and finish three scenes with intelligible audio, edit and captions.
3. The project reopens after restart, identifies missing media, and keeps locked shots unchanged when another scene is rerendered.
4. Local work incurs no cloud charges; all remote media disclosure, likeness and pricing approvals are explicit.
5. One actual rendered film, revision and export plus reproducible test/build receipts exist. Screenshots and architecture alone do not satisfy release.

**Next build seam:** catalog/pantry scale, derivative reconciliation and truthful thumbnail/search UI, not premature public beta.
