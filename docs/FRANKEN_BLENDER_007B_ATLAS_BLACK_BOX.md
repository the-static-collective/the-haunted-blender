# FRANKEN BLENDER 007b — MOTION ATLAS BLACK BOX\n\nStatus: experimental descendant of Atlas Executor 007.\n\n## Every crossing leaves evidence\n\n007 already has an immutable execution journal. 007b turns that journal into a persistent empirical Motion Atlas.\n\nThree evidence lanes remain distinct:\n\nPUBLIC / CATALOG — pages, registries, model listings, crawler facts\nACCOUNT-LOCAL OPERATIONAL — capabilities, quotes, submit, status, fetch\nFILM-LOCAL CREATIVE — explicit human KEEP disposition\n\nNo lane inherits authority from another.\n\n## Automatic telemetry\n\nThe 007 executor now emits sanitized operational events automatically when it records provider capabilities, exact quotes, submits, statuses, and candidate fetches. Human candidate KEEP emits a separate creative event.\n\nEvents are hash-linked and each lane has its own HEAD. Verification fails closed if an event changes.\n\n## Privacy-default telemetry\n\nDefault Black Box events exclude generation prompts, local paths, filenames, account ID, and account name. Submit events store a SHA-256 of the vendor request ID rather than the raw vendor ID. Film-local creative evidence binds scene SHA and window ID without copying the scene title or prompt.\n\n## Anti-taste-model law\n\nOBSERVATION != PREFERENCE\nKEEP != UNIVERSAL QUALITY SCORE\nREJECTED TAKE != BAD MODEL\nONE USE != PROVIDER REPUTATION\n\n007b may record that one candidate was presented and another was KEEP'd. It may not silently infer a universal provider ranking.\n\n## Aggregation\n\nThe summary layer counts factual observations only: operational event count, completed jobs observed, definitive failures observed, timeout/unresolved observations, candidates KEEP'd, quoted USD micros observed, and quoted generated seconds observed.\n\nSUMMARY != QUALITY RANKING\nOBSERVED ACCEPTANCE RATE != UNIVERSAL MODEL QUALITY\nMISSING EVENTS != ZERO EVENTS\n\n## Long-term consequence\n\nThe Atlas can eventually distinguish advertised cheap, observed cheap, observed available, observed reliable, and observed often KEEP'd as separate claims with separate provenance.\n\nThat is evolutionary memory for the motion organism.
