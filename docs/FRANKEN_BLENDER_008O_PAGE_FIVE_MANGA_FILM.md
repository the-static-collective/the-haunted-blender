# FRANKEN BLENDER 008o — PAGE FIVE MANGA FILM

008o is the first **moving, audible descendant** of the 008n narrative custody chain.

It consumes the admitted Page-5 performance plan from:

```text
0.022101 — THE BUS THAT JOINED THE BAND
Page 5 — A page you can hear
```

and renders a real MP4 locally.

## What moves

The eight admitted 008n beats become limited manga motion:

```text
guitar string        → visible string vibration
loose mug lid        → bounded lid rattle
Grace's breath       → abstract profile + breath arcs
seat spring          → visible spring compression
fingers / rail       → contact + tap motion
window edge          → frame rattle
Lumi / blinker       → watcher + ordinary blinker timing
whole bus interior   → stable wide return
```

No source identity is replaced by the animation. Every visible beat carries the exact 008n source-particular hash into the render receipt.

## What becomes audible

008o also creates a deterministic soundtrack with only local synthesis:

```text
guitar string        → decaying pluck
mug lid              → metal-like clink
Grace's breath       → soft deterministic noise
seat spring          → paired spring tones
fingers / rail       → taps
window edge          → bounded rattle
blinker              → clocked ticks
whole interior       → low room tone
```

The audio is explicitly derived performance sound.

```text
SYNTHESIZED SOUND != SOURCE RECORDING
AUDIBLE RHYME != CAUSAL PROOF
```

The film therefore makes the page audible without claiming that the synthesized sound is historical evidence.

## Receipt

The receipt binds:

- 008n source / proposal / admission / plan ids;
- final MP4 SHA-256;
- dimensions, frame count, FPS, duration and audio presence;
- every rendered beat;
- each beat's exact source-particular id and hash;
- exact frame range occupied by each beat;
- deterministic audio-plan id and WAV SHA from the render pass;
- zero provider generations / credits / spend.

## The visual language

The first renderer deliberately uses a monochrome construction-paper / manga animatic grammar rather than pretending to be a finished anime production.

That makes the proof inspectable:

```text

```

## Current boundary

008o does **not yet** claim that the current film uses harvested pixels from an owned 008m page.

This first proof is generated from the source-particular geometry and admitted staging itself.

That boundary is intentional:

```text
MOVING DESCENDANT PROVEN
OWNED-PIXEL DESCENDANT NOT YET PROVEN
```

The next crossing can replace or enrich these deterministic glyphs with an 008m → 008h owned Parts Drawer while preserving the same 008n beat hashes.
