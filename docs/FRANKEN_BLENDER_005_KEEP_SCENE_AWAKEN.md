# FRANKEN BLENDER 005 — KEEP → SCENE → AWAKEN

Status: experimental descendant of Cutout Compiler 004.

## The instrument closes one loop

004 lets a human watch six unborn moving futures without changing history.

005 lets a KEEP become a longer deterministic scene.

```text
SIX-UP
  ↓ human KEEP p4
KEEP DESCENDANT
  ↓
TRACK TIMING
  ├─ PlayDeck section gates
  └─ Full Measure lyric cues
  ↓
LONGER CUTOUT SCENE
  ↓
bounded awakening windows
  ↓
accepted moving take may replace one window
  ↓
new private scene receipt
```

## Timing is evidence, not authority

005 accepts PlayDeck `TrackSpec 0.1`-compatible section gates and the existing
Full Measure `full-measure.lyrics.v1` cue format.

It combines them into:

- explicit sections;
- cue-to-section bindings;
- a maximum of three proposed awakening windows.

A chorus or bridge may *open a door*. It does not compel generation.

```text
TIMING != MOTION AUTHORITY
LYRIC CUE != GENERATION COMMAND
AWAKENING WINDOW != ACCEPTED TAKE
```

## KEEP grows the scene

The kept DREAMBREEDER proposal receives section-relative motion additions:

- intro → hold / parallax
- verse → hold / wind / parallax
- pre-chorus → step / drift-up / wind
- chorus → step / raise-world / reveal-sky / backlight
- bridge → freeze / echo / misregister
- breakdown → separate / misregister
- outro → return / open-late

The same addressed still organs therefore behave differently as the song changes
without requiring fresh generated pixels for every section.

The section MP4s are concatenated into one longer private cut.

KEEP still does not mean publication and the cut is not yet a resolved
DREAMBREEDER performance.

## Rare awakening is now bounded

An awakening window may be replaced only by a Blender video address that resolves
through the existing filmmaker-accepted video resolver.

That means the moving take must already have:

- a matching accepted-take witness;
- matching creative request lineage;
- matching admission receipt;
- unchanged local MP4 bytes;
- a valid SHA-256 address.

The accepted take is then trimmed/scaled into only the selected timing aperture.

```text
WINDOW != ACCEPTANCE
ACCEPTANCE != PUBLICATION
ACCEPTED TAKE MAY REPLACE ONLY ITS BOUNDED WINDOW
```

This is the bridge from cheap puppet film into expensive moving-world footage
without letting the provider become the editor.

## Why this is the first real movie-growing loop

```text
possibility
  → preview
  → KEEP
  → timed scene
  → rare moving-world crossing
  → private witnessed cut
```

What remains for 006 is to make the *provider request itself* portable and
replaceable:

```text
awakening window
  → opaque request
  → cheapest/free available generator
  → candidate
  → human acceptance
  → bounded splice
```

That is where the plugin swarm becomes one interchangeable motion organ.
