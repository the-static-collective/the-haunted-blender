## What 008p does

008p consumes the same admitted 008n Page-Five plan used by 008o.

For every beat it:

1. selects a deterministic manual staging window from the admitted donor;
2. applies a tiny bounded Ken Burns drift;
3. enlarges the source pixels to the frame;
4. enlarges the exact RGB witness and applies the readable 008o manga-particular grammar over those pixels;
5. uses the same deterministic 008o audio plan;
6. records both the narrative-particular hash and the pixel-donor hash.

The donor is present in **every rendered frame**.

## Important semantic boundary

The crop windows are editorial staging.

They are not object detection, character recognition, or semantic segmentation.

```text
STAGING CROP != SEMANTIC SEGMENTATION
OWNED PIXELS != CHARACTER IDENTITY
```

For example, a crop may be selected because it is a useful human-scale region of the shared composition. That does not assert that a pictured person is Grace, Lumi, Lu, or any other named character.

The narrative source remains 008n.

```text
PIXEL DONOR != NARRATIVE AUTHORITY
```
