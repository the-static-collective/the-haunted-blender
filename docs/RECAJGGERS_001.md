# Recajggers 001 — a small cabinet of future Blender cartridges

The first executable experiment is [Time Slice 001](TIME_SLICE_001.md). These are *candidate* transformations, not implemented adapters or claims about what a viewer perceived. A transformed output gets fresh byte identity and its own receipt; the source, scene acceptance, and permission to use it stay separate.

| Candidate | Open tool / small emulation | First bounded test | Boundary to keep |
| --- | --- | --- | --- |
| Video feedback | [Hydra](https://github.com/hydra-synth/hydra) or a small local frame feedback filter | Let each opening of the door leave a receding image of earlier openings | A visual echo is not an event witness. Hydra is AGPL; assess obligations before embedding. |
| False depth / 2.5D | [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2) + Blender planes | Cut door/frame/background from one still, assign *estimated* depth, move a camera slightly | Store the depth estimate as a derived material, not measured geometry. Small and larger model weights have different licenses. |
| Image material mutations | [G’MIC](https://gmic.eu/) CLI | Render contour and displacement masks of a source frame as separate assets | A transformed texture cannot inherit the source's creative role or rights. |
| Word choreography | [Manim](https://github.com/ManimCommunity/manim) or [Revideo](https://github.com/midrender/revideo) | Reveal an exact, source-linked phrase through the doorway at authored frame times | Keep the textual witness, exact characters, display decisions and audience-knowledge proposal distinct. |
| Photo reconstruction | [COLMAP](https://github.com/colmap/colmap) with Blender | Reconstruct one photographed location from overlapping views and render an alternate camera move | Needs matching views; a single still supports a 2.5D proposal, not this reconstruction. |
| Editable handoff | [OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO) | Export a cut decision list without changing the accepted scene | An interchange timeline is not a rendered MP4 or renewed acceptance. |
| HTML to film | [html-video](https://github.com/nexu-io/html-video), [Revideo](https://github.com/midrender/revideo), or existing Hyperframes | Render one HTML projection as a video and admit its bytes to the Pantry | Check each engine and template's licenses and receipt scope before exchange. |
| Optical flow fabric | [OpenCV](https://opencv.org/) | Track the moving door edge and carry a bounded texture along its apparent movement | Flow estimates image motion; it does not establish real object movement. |

Possible next composition: accepted door take → time-sliced PNG → new texture proposal in a second shot. The second shot requires an explicit admission and filmmaker choice. Acyclic receipts can describe a creative return to an ancestor's material without treating the return as inherited authority.
